# 알림·앱 화면안

목표는 보호자가 측정 상태와 알림의 불확실성을 알아볼 수 있게 하는 것이다. 이번 패키지의 화면은 미구현 설계 시안이며 실제 사용자 연구 결과가 아니다.

| 상태 | 앱 표시 | 처리 제안 |
|---|---|---|
| 정상 수집 | 마지막 동기화 시각, 신호 품질 | 연구모드에서만 성인 스트레스 분류 점수 표시 |
| 센서 불량 | 측정 불가 · 착용 상태 확인 | 위험점수 및 위험 알림 보류; 마지막 점수를 현재 값처럼 표시하지 않음 |
| BLE 연결끊김 | 연결 끊김 · 마지막 수신 시각 | 연결 안내, 오래된 점수의 알림 금지 |
| 연구 점수 상승 | 연구 점수 변화 · 맥락 확인 | 검증된 위험 발생 확률이나 멜트다운 경고라고 명명하지 않음 |
| 장기 검증 모델의 알림 | 상태 확인을 도와주세요 · 불확실성·시각 | 보호자가 선택 가능한 조용한 지원; 당사자·임상 검토 필요 |

기본 아동 손목 진동은 꺼둔다. 보호자 휴대폰의 조용한 알림부터 수용성을 검토한다. 반복 알림 억제·cooldown·수신확인·담당자 인계·수업 중 알림 정책은 실제 사용성과 함께 평가한다.

원음 저장은 기본 설계에 포함하지 않는다. 사건 기록은 최소한의 종류·onset/offset·확신도·맥락·조치시각을 사용하며 접근권한·보존기간·삭제·암호화를 설계한다. 아동의 거부·철회와 보호자 동의, 기관 윤리 절차는 실제 자료 수집 전에 확인한다.

시안의 숫자는 성능이나 실측을 뜻하지 않는다. [앱 시안](APP_MOCKUP.html)은 숫자 대신 상태·미검증 표시를 사용한다.
