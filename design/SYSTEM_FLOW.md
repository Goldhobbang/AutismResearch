# 시스템 흐름과 상태 (제안, 미제작)

**현재 연구 데모:** 성인 실험 스트레스 분류. **장기 시스템:** 별도 ASD 사건 데이터와 전향 검증을 통과해야 하는 조기 위험 알림. 두 모델의 명칭·임계값·근거를 섞지 않는다.

1. EDA/PPG/ACC를 native rate로 취득하고 하드웨어 타임스탬프·FIFO 유실을 기록한다.
2. 착용·접촉·포화·flatline·누락 등 품질을 검사한다. 접촉 판별 기능은 아직 구현·검증되지 않았다.
3. Mic/Light는 환경 맥락 보조 센서로 별도 검증한다. 유효 과거60초 버퍼에서15초마다 특징을 계산한다. 센서 rate가 바뀌면 특징과 모델을 다시 검증한다.
4. train에서 학습한 imputer/scaler/모델을 적용한다. 점수는 보정 전 분류 점수이며 실제 위험확률로 표시하지 않는다.
5. 품질 불량이면 점수를 보류한다. BLE 전송에는 모델 버전·시각·품질·점수·유효기간을 포함한다.
6. 앱은 측정불가 / 연결끊김 / 오래된측정 / 연구점수 / 알림검토 상태를 구별한다. 연구 시뮬레이션의 2회 연속 초과·60초 cooldown은 임상 기준이 아니다.
7. 보호자는 알림을 검토하고 맥락·조치·관찰시각을 남긴다. 앱은 자동 진단 또는 강제 개입을 수행하지 않는다.

현행은 ESP32-S3 BLE-only다. EDA만 AFE/ADC를 거치고 PPG·IMU·Light는 각 디지털 인터페이스, Mic는 호환 디지털 음향 경로로 연결한다. 원음은 저장하지 않는다. BLE 경로는 손목→가까운 휴대폰/태블릿이다. 휴대폰 인터넷을 통한 전달은 별도의 네트워크·계정·수신확인 정책을 요구한다. DRV2605L를 통한 진동과 제한된 특징/event 로깅을 두며, 아동 손목 진동은 기본 비활성 제안이다.
