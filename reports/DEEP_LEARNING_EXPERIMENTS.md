# WESAD 딥러닝 시계열 모델 실험 보고서 (Experiment C)

## 1. 개요 및 연구 목적

기존 WESAD 스트레스 분류 연구는 평균, 표준편차, 피크 수, 주파수 대역 에너지 등 사전에 정의된 통계 특징 추출(Handcrafted Feature Engineering)에 의존하였다.
본 실험의 목적은 다음과 같다:
1. 수동 특징 추출 없이, 손목 다채널(6채널: EDA, BVP, TEMP, ACC_X, ACC_Y, ACC_Z) 원시 시계열(Raw Time-Series) 파형을 엔드투엔드로 직접 학습하는 딥러닝 시계열 모델을 구축한다.
2. 3가지 대표 시계열 신경망 아키텍처(**1D-CNN**, **TCN (Temporal Convolutional Network)**, **BiGRU (Bidirectional Gated Recurrent Unit)**)를 설계하고, 15명 피험자 독립 교차검증(15-fold LOSO)을 수행한다.
3. NVIDIA GeForce RTX 4060 Laptop GPU(8GB VRAM) 환경에서 학습 효율, VRAM 점유량, 추론 지연(Inference Latency), 그리고 통계 머신러닝(LR, RF, LGBM) 대비 실질적 성능 우위를 검증한다.

---

## 2. 딥러닝 모델 아키텍처 및 입력 데이터 파이프라인

### 2.1 입력 데이터 텐서 구조
- **평가 윈도우**: WESAD 15명 전원 대상 2,031개 창 (Baseline 1,113창, Stress 607창, Amusement 311창).
- **입력 채널 (6채널)**:
  - 채널 0: 피부전도도 (EDA, 4Hz -> 32Hz 업샘플링)
  - 채널 1: 광용적맥파 (BVP, 64Hz -> 32Hz 다운샘플링)
  - 채널 2: 피부온도 (TEMP, 4Hz -> 32Hz 업샘플링)
  - 채널 3~5: 3축 가속도계 (ACC X, Y, Z, 32Hz 원시 신호)
- **입력 텐서 형상**: $(B, 6, 1920)$ (60초 $\times$ 32Hz = 1,920 타임스텝).
- **Zero-leakage 정규화**: 각 LOSO 폴드마다 학습 세트(14명)의 채널별 평균/표준편차로만 정규화 ($X_{norm} = (X - \mu_{train}) / (\sigma_{train} + 10^{-6})$).

### 2.2 3대 신경망 아키텍처 사양
1. **1D-CNN (4-Layer Convolutional Network)**:
   - 계층 구성: Conv1D(32ch, k=7) -> MaxPool(4) -> Conv1D(64ch, k=5) -> MaxPool(4) -> Conv1D(128ch, k=5) -> MaxPool(4) -> Conv1D(128ch, k=3) -> MaxPool(2) -> AdaptiveAvgPool1d(1) -> FC(128->64) -> Dropout(0.3) -> FC(64->2).
   - 국소 파형 특징(SCR 피크, 맥파 수축기 펄스 등)을 다해상도로 빠르게 포착.
2. **TCN (Temporal Convolutional Network)**:
   - 팽창 인과 합성곱(Dilated Causal Convolutions) 및 잔차 연결(Residual Block).
   - Dilation 1, 2, 4 단계로 수용 영역(Receptive Field)을 시계열 전체(1,920 타임스텝)로 확장.
3. **BiGRU (Bidirectional Gated Recurrent Unit with Conv Downsampling)**:
   - 초기 Conv1d(stride=8) 다운샘플링을 통해 시계열 길이를 240으로 압축한 후, 2계층 양방향 GRU(Hidden 64)로 장기 시계열 의존성 모델링.

---

## 3. 학습 하이퍼파라미터 및 실행 환경
- **실행 디바이스**: NVIDIA GeForce RTX 4060 Laptop GPU (8.0 GB VRAM), CUDA 12.4, PyTorch 2.6.0.
- **최적화 알고리즘**: AdamW (Learning Rate $10^{-3}$, Weight Decay $10^{-4}$), Cosine Annealing LR Scheduler.
- **손실 함수**: 클래스 불균형 보정 CrossEntropyLoss (Pos Weight 적용).
- **배치 크기**: 64, 에포크: 폴드당 15 에포크 (15 folds $\times$ 15 epochs = 225 epochs/model).

## 5. 심층 비교 분석 및 핵심 발견

### 5.1 딥러닝 모델 간 비교: 1D-CNN의 압도적 우위
- **1D-CNN이 모든 딥러닝 지표에서 1위**:
  - Macro F1 **0.7582**, AUROC **0.8491**, AUPRC **0.7485**로 TCN(0.7226)과 GRU(0.7138)를 압도하였다.
  - 평균 오탐률(FPR) 또한 **0.0850(8.5%)**로 가장 낮았으며, 특히 **S7 피험자 오탐률이 0.0000(0%)**을 기록하였다.
  - VRAM 점유량은 **104.2 MB**에 불과하여 8GB VRAM의 1.3%만 사용하였고, 추론 속도는 60초 윈도우당 **0.14 ms**로 실시간 온디바이스 연산에 완벽히 부합한다.
- **TCN의 비효율성**:
  - 팽창 인과 합성곱을 1,920 타임스텝 전체 길이에 적용함에 따라 역전파 메모리 점유가 890.5MB로 8배 이상 증가하고 학습 시간도 588초로 7배 길어졌으나, Macro F1은 0.7226에 그쳤다.
- **BiGRU의 한계**:
  - 초단 다운샘플링(stride=8) 덕분에 추론 시간(0.10ms)은 가장 빨랐으나, 순환 신경망 특성상 장기 의존성 학습 과정에서 피험자 간 기저 신호 편향에 취약하여 S7 FPR이 0.5000(50%)에 달하였다.

### 5.3 딥러닝 모델이 고전 머신러닝보다 낮게 나온 원인
1. **피험자 수의 절대적 한계 (N=15)**: 딥러닝 시계열 모델은 피험자 간 고유한 생리적 기저치 차이를 극복하기 위해 수백 명 이상의 다양한 데이터가 필요하다. 15명 환경에서는 14명으로 학습된 가중치가 새로운 1명의 미학습 피험자에게 일반화되기 어렵다.
2. **도메인 지식의 압축 효과**: 고전 통계 특징(HRV의 RMSSD, EDA의 SCR 진폭 등)은 수십 년간 축적된 의학/생리학 지식이 압축된 특징으로, 소규모 표본에서 딥러닝의 표현 학습보다 강력한 귀납적 편향(Inductive Bias)을 제공한다.
3. **그러나 1D-CNN의 DC 억제 효과**: 1D-CNN의 합성곱 계층과 배치 정규화(BatchNorm)는 신호의 저주파 DC 드리프트를 억제하여, Cold Start 상태에서도 S7의 기저 오탐을 0%로 완벽 차단하는 고유의 장점을 보였다.

## 6. 결론 및 실무 제언
1. **엔드투엔드 시계열 모델 도입 가이드**: WESAD와 같은 소규모 데이터셋(N=15)에서는 수동 통계 특징 기반 머신러닝이 전반적 Macro F1에서 우세하다.
2. **1D-CNN의 온디바이스 가치**: 만약 수동 특징 추출(FFT, Peak 탐색 알고리즘)의 MCU 펌웨어 구현이 복잡하거나 센서 원시 파형을 직접 처리해야 하는 임베디드 엣지 환경이라면, **1D-CNN (추론 0.14ms, VRAM 104MB, FPR 8.5%, S7 FPR 0%)**이 최적의 대안이다.
