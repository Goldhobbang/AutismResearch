# 11장 발표 구성과 사용할 수 있는 문장

상태: 실제 성인 데이터 성능은 실행 전에는 N/A. 아래 문장은 실행·감사 상태에 따라 선택한다. 합성 코드 검사, 성인 스트레스 분류, 아동 위험행동 예측, 제품 실측은 다른 주장이다.

| 장 | 제목·핵심 문장 | 그림/표 | 근거 |
|---|---|---|---|
| 1 | **문제와 필요성** — 보호자가 아동의 불편을 더 일찍 알아차리는 데 도움이 되는 기술을 연구한다. 감각과부하가 항상 위험행동으로 이어지는 것은 아니다 | 목표 사용상황과 현재 연구범위 | 연구 목적 L4 |
| 2 | **선행연구는 무엇을 예측했나** — 공격·ED·전조·혼합SIB 연구에서 신호가 보고되었으나 대상과 평가가 다르다 | 행동/분할/미래구간/지표 표. AUROC와accuracy를 같은 막대로 비교하지 않음 | LIT-01~05/L2 |
| 3 | **이번 목표와 장기 목표** — 이번에는 성인 스트레스 분류 방법을 검증한다. 아동60초 경보는 후속 가설이다 | 검증범위 두 칸 | EXP-01/02 대기, GOAL-01/L4 |
| 4 | **제작 없는 하드웨어 설계** — ESP32-S3와 EDA·PPG·IMU, Mic/Light 맥락 보조, BLE·DRV2605L·로컬 특징로그 | 제품 블록도·상하면/측면 배치·모듈형 메모리·BOM | design/ 공식 사양 DOC + L3 계산 |
| 5 | **동작 시나리오** — 신호품질을 먼저 확인하고 측정불가와 모델 점수를 구분한다 | 측정불가/연결끊김/연구점수 앱화면 | 설계 L3/L4; 실제 경보효과 아님 |
| 6 | **AI 연구 설계** — 60초 과거창·15초 hop·참가자 전체 분리, Dummy/LR/RF와7개 센서 조합 | LOSO+내부검증 도식 | EXPERIMENT_REGISTRY.md, configs/ |
| 7 | **직접 실행한 것** — 원자료 인수와 학습이 끝났다면 실제 데이터·환경·명령·참가자 수를 제시한다 | 원자료 감사→특징→LOSO 산출 흐름 | L1 로그. 미실행이면 테스트와 다운로드 blocker만 제시 |
| 8 | **성과와 검증 범위** — 모델 최고값뿐 아니라 모든 참가자의 분포와 누락을 보고한다 | 실제 subject_performance/model_comparison/sensor_ablation/confusion_matrix | L1 실험 완료 때만 삽입. 현재 수치 N/A |
| 9 | **기대효과는 가설** — 적절한 알림이 도움이 될 가능성을 검증할 기반을 만든다 | 향후 사용자·임상 평가 질문 | L4. 멜트다운 감소를 실험결과로 표현 금지 |
| 10 | **한계와 다음 단계** — 성인 실험실 상태에서 아동 일상 사건으로 일반화하려면 별도 onset·긴 음성시간·동의·현장 검증이 필요하다 | 단계별 데이터·윤리·성능 게이트 | 연구제안 L4 |
| 11 | **결론** — 방법의 재현성과 주장 범위를 갖추는 것이 이번 연구의 성과다 | 완료/보류/미검증 표 | QUALITY_REPORT.md + EVIDENCE_LEDGER.md |

## 현재 실행이 막힌 경우의 발표 문장

> “선행연구를 근거로 성인 스트레스 분류와 아동 위험행동 예측을 분리한 실험을 설계했습니다. 구현의 시간 경계와 피험자 분리를 검사했지만, 공식 원자료 다운로드가 실행환경 정책에 막혀 실제 데이터 성능은 아직 제시하지 않습니다. 이를 해결한 뒤 사전에 고정한 LOSO와 센서 제거 실험을 수행합니다.”

검사가 통과하기 전에는 “검사했습니다” 뒤에 실제 통과/실패 항목을 구체적으로 붙인다. 다운로드 실패 자체가 예측 가설을 반증한 것은 아니다. H1/H2/H3은 미실행 상태다.

## 실제 실험이 완료된 뒤의 결과 문장 틀

> “WESAD 성인 __명의 손목 신호에서, 60초 단일상태 창을15초마다 구성했습니다. 같은 참가자의 모든 창을 외부 시험으로 분리한 LOSO에서 __모델의 참가자 평균 AP는__, stress F1은__, balanced accuracy는__였습니다. 참가자별 범위는__였고 전체센서−EDA의 AP 차이는__였습니다. 이 수치는 실험실 스트레스 분류에 한정됩니다.”

> “PhysioNet의 검증된 운동구간에서 EDA+BVP 모델과 ACC를 추가한 모델의 false-stress 비율을 동일 참가자 분할로 비교했습니다. 차이는__였으며 세션·프로토콜 교란이 남습니다.”

빈칸은 실제 출력만으로 채운다. 유효 피험자가15명 미만이면 이유와 실제 수를 표시한다. CI는 참가자 bootstrap이며 작은 표본·공유 훈련 fold의 한계가 있다.

## 심사위원 질문과 답변

| 질문 | 답변 |
|---|---|
| 84% 예측 연구가 있는데 무엇이 새롭나? | .84는 개인별 AUROC다. 우리는 고정된 분할에서 센서 기여·개인차·운동 혼동과 구현의 재현성을 검증한다 |
| 스트레스 모델이 멜트다운을 예측하나? | 아니다. 모집단과 정답이 다르다. 아동 onset 자료 없는 사건지표는 N/A다 |
| REACT는 실시간 성공 아닌가? | 다음방문 기록의 stream 모사와 label refinement가 포함된다. 장기 보호자 알림·임상효과 검증으로 확대하지 않는다 |
| 왜 딥러닝을 쓰지 않았나? | 독립 참가자가 적어 단순 기준모델과 공정 비교가 우선이다. 복잡도 증가는 검증할 가설이지 성능 보장이 아니다 |
| 운동을 감각과부하로 보는가? | 아니다. D2는 정신과제와 구조화운동을 구별하는 제한된 실험이다. 놀이·일상 모든 활동의 대리 정답이 아니다 |
| 점수가 낮으면 실패인가? | 실행된 실험이라면 어떤 센서·모델 가설이 지지되지 않았는지 보고한다. 미실행은 낮은성능과 다른 상태다 |
| 배터리는 얼마나 가나? | BOM·전류 가정으로 계산한 시나리오만 있다. 실측 수명과 MCU 지연은 아직 없다 |
| 휴대폰 없이 원거리 알림이 되나? | 현행 BLE 설계는 근처 휴대폰·태블릿이 필요하다. 연결이 없으면 원거리 전달을 보장하지 않는다 |
| 전조가 없는 사건은 몇%인가? | 현재 자료와 모델 미탐지로 그 비율을 추정할 수 없다 |
| 알림이 위험을 줄였나? | 아직 검증하지 않았다. silent-mode 예측 검증 후 별도의 비교 중재연구가 필요하다 |

## 모든 결과 그림의 필수 캡션

`성인 실험실 스트레스 분류 / 데이터·버전 / 라벨 정의 / 60초창·15초hop / subject-LOSO / 내부검증 임계값 / 실제 참가자 수 / 제외기준 / 합성 여부 / ASD 사건예측 아님`.

실제 데이터가 없으면 성능 그래프를 합성 점수로 채우지 않는다. 방법 도식·설계도와 명시적인 실행상태 표를 사용한다.
