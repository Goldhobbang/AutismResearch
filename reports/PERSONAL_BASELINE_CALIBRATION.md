# WESAD 개인별 기준선 보정 및 오경보 억제 연구 보고서 (Experiment D)

## 1. 개요 및 연구 배경

기존 WESAD 벤치마크 모델(LR ALL)의 가장 심각한 실용적 결함은 **특정 참가자(S7)에 대한 극단적인 오탐률 (FPR 85.42%)**이었다.
- S7 피험자는 기저(Baseline) 상태임에도 불구하고 높은 피부전도도(SCL)와 고유의 생리적 DC 편향(Baseline Bias)으로 인해 거의 모든 구간에서 스트레스로 오탐되었다.
- 실제 웨어러블 디바이스 환경에서 시간당 8.5회 이상의 오경보가 울리면 사용자는 장치를 신뢰하지 못하고 착용을 중단하게 된다.
- 본 실험의 목적은 사전 보정 데이터(Cold Start vs Calibration Available)를 활용하여:
  1. 기저 신호 편향을 제거하는 8가지 보정 전략을 구현·비교한다.
  2. S7의 극단적 오탐을 억제하면서도 실제 스트레스 탐지율(Stress Recall)을 100% 보존하는 최적 보정 알고리즘을 도출한다.
  3. 단순 창(Window) 단위 지표를 넘어 실제 경보 에피소드(Alarm Episode) 및 시간당 오경보율(FAR/hr)을 정량 평가한다.

---

## 2. 보정 전략 및 실험 설계

15명 피험자(2,031창)에 대해 다음 8가지 보정 정책을 15-fold LOSO 환경에서 비교하였다:

1. `fixed_05`: 사전 보정 없는 고정 임계값(0.5) 적용 (Cold Start Baseline 1).
2. `tuned_val`: 검증 세트 기반 최적 임계값 적용 (Cold Start Baseline 2, 기존 LR ALL).
3. `calib_prob_5min`: 착용 초기 5분간 Baseline 평균 예측 확률($\bar{p}_{base}$)을 감산하여 임계값 동적 상향 ($P_{adj} = P - \bar{p}_{base}$).
4. `calib_prob_adaptive_5min`: 5분 기저 평균에 기반하여 참가자별 맞춤 판별 임계값 설정 ($\theta = \max(0.5, \bar{p}_{base} + 0.15)$).
5. `calib_prob_adaptive_full`: 전체 Baseline 구간을 알고 있다고 가정한 이론적 상한선 (Oracle Upper Bound).
6. `calib_hysteresis_5min`: 진입 임계값(High=0.65)과 해제 임계값(Low=0.40)을 분리한 슈미트 트리거(Schmitt Trigger) 히스테리시스 필터.
7. `feature_delta_5min`: 착용 초기 5분 Baseline의 각 특징별 평균값($\mu_{base}$)을 원시 특징에서 차분 ($x_{norm} = x - \mu_{base}$).
8. `logit_shift_5min`: 로짓(Logit) 도메인에서 5분 기저 오프셋 보정.

## 4. 결정적 성과: `feature_delta_5min` 전략의 기여

### 4.1 S7 오탐 문제의 완전한 해결
- 기존 Baseline 모델에서 S7은 FPR 0.8542 (F1 0.4875)로 사실상 정상 사용이 불가능한 수준이었다.
- 그러나 착용 후 5분 기저 평균을 차분한 **`feature_delta_5min` 전략 적용 시**:
  - **S7 FPR: 0.8542 -> 0.0208 (97.6% 급감)!**
  - **S7 Stress F1: 0.4875 -> 0.9067 (86.0% 향상)!**
  - S7 오경보 에피소드: 세션당 6회 -> 1회로 감소.

### 4.2 전체 참가자 대상 일반화 성능
- **평균 FPR**: 기존 0.1619에서 **0.0538**로 **66.8% 대폭 감소**.
- **평균 Stress F1**: 기존 0.7425에서 **0.8205**로 개선.
- **스트레스 실제 탐지율 (Detection Rate)**: **100.0%** 완벽 유지 (15명 피험자의 모든 실제 스트레스 에피소드 검출).
- **에피소드 기준 시간당 오경보**: 시간당 8.57회에서 **4.04회**로 절반 이상 감소.

## 6. 결론 및 실무 구현 권고안
1. **Cold Start의 한계 확인**: 사용자 맞춤 기저치가 없는 Cold Start 모델은 개인간 생리 신호 기저치 편차를 극복할 수 없다.
2. **착용 초기 5분 Calibration 시퀀스 도입**:
   - 웨어러블 디바이스 착용 직후 "편안한 휴식 상태 5분"을 유지하도록 안내하고, 이 5분간의 특징 평균 벡터 $\mu_{base}$를 로컬에 저장한다.
   - 이후 실시간 추론 시 $x - \mu_{base}$를 모델의 입력으로 제공함으로써 S7과 같은 이상 오탐을 사전 차단한다.
3. **오경보 억제 효과**: 시간당 오경보가 8.57회에서 4.04회로 절반 이상 줄어들어 디바이스의 상용화 신뢰성을 획기적으로 개선한다.
