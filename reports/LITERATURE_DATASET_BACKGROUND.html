2. 기존 논문 근거표

표의 ‘미보고’는 확인한 원문 범위에서 해당 운영 지표를 제시하지 않았다는 뜻이다. ‘미확인’은 접근 또는 세부 검증 한계로 수치를 확정하지 못했다는 뜻이다. 서로 다른 논문의 수치를 순위표로 비교하지 않는다.

Goodwin 원문 일부는 PMC 직접 열람이 차단되어 PubMed와 PMC의 색인된 원문 Results/Methods로 교차 확인했다. PreMAC은 원문 PDF를 확인했다. Imbiriba 본문과 REACT 출판사 전문, Kim 출판사 전문을 확인했지만 일부 보충파일은 접근하지 못했다. 접근하지 못한 부록 값을 ‘미보고’로 바꾸지 않았다.

PreMAC의 혼동행렬은 행·열 제목과 FP/FN 기호가 일치하지 않는 부분이 있고 개인표는 예시 모델이다. 따라서 이를 임의로 고쳐 집단 평균 정밀도·재현율로 제시하지 않았다. 보고된 accuracy와 전조 목표 자체를 우선 인용한다.

Kim의 설정은 다음과 같다. 관찰 종료를 t라 할 때 최소 대기시간과 양성 판정 구간을 분리해야 한다. 원문 Table 1.

설정 latency 미래 판정 구간 폭 사건을 찾는 시각
H1 3초 7초 t+3 ~ t+10초
H2 15초 15초 t+15 ~ t+30초
H3 30초 30초 t+30 ~ t+60초
H4 60초 30초 t+60 ~ t+90초
H5 60초 60초 t+60 ~ t+120초

H5는 최소120초 전 경고가 아니다. 구간 폭이 늘면 양성 비율도 달라지므로 PR 성능 향상이 ‘더 먼 미래가 본질적으로 더 쉽다’는 증거가 되지는 않는다. 각 조건의 양성 비율을 함께 비교해야 한다. 논문이 제시한 4.4:1도 윈도 기반 false:true 비율이며, 독립 경고 4.4회/일이라는 뜻이 아니다.

추가 최신 근거: Kartha et al., 2026 프리프린트는 9명의 아동·청년, 교실 자료 약110.7시간, EDA·ACC·체온으로 미래 행동 분석을 보고한다. 현장 수집의 진전이지만, 이 보고서는 프리프린트임을 명시하며 상용 제품 검증으로 취급하지 않는다.

AUROC 0.84의 해석: 해당 평가 분포에서 양성 표본의 점수가 음성보다 높게 매겨지는 순위 구분 능력이다(동점 처리 포함). ‘84%를 맞혔다’, ‘경고의84%가 맞다’, ‘사건84%를 예측했다’ 중 어느 것도 의미하지 않는다. 정밀도는 임계값·사건 빈도에 의존한다. 지표 정의.
